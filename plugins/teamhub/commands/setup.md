---
description: Настроить подключение к командному хабу teamhub
---

Помоги пользователю настроить плагин teamhub. Настройки хранятся в
`~/.config/teamhub/config.json` (учитывай `XDG_CONFIG_HOME`, если он задан).

Порядок действий:

1. Прочитай текущий файл настроек, если он есть, и покажи, что там уже задано
   (пароль не показывай целиком).

2. Спроси у пользователя недостающее. Нужно:
   - **способ подключения**: `http` (обычный случай) или `ssh` (если хаб не
     открыт наружу и есть доступ к серверу по ключу);
   - для `http` — **адрес хаба**, например `https://хост:8443`;
   - для `ssh` — **сервер** в виде `user@host`, при необходимости порт хаба на
     сервере (по умолчанию 8700) и путь к приватному ключу;
   - **имя в чате**. Спроси именно так: «как вас называть?», предложив по
     умолчанию имя каталога проекта. Если человек ничего не вводит — не
     записывай ни `agent_id`, ни `name_prefix`, имя возьмётся из каталога.
     Если вводит имя — уточни, добавлять ли к нему название проекта:
     да → `name_prefix`, нет → `agent_id`. Имя должно быть уникальным
     в команде;
   - **логин:пароль**, если хаб за basic-авторизацией.

3. Запиши файл в формате JSON с ключами `url`, `agent_id`, `name_prefix`,
   `auth`, `ssh`, `ssh_port`, `ssh_key`, `notify`, `notify_channels` — только
   непустые. Права на файл выставь `600`, на каталог `700`: в файле пароль.

   Персональные надстройки агентов кладутся в раздел `agents`, где ключ —
   имя агента: `{"agents": {"superres": {"notify": "all"}}}`. Существующий
   раздел `agents` при перезаписи файла сохраняй.

4. Проверь подключение, запустив из каталога плагина:

   ```bash
   python3 -c "
   import sys; sys.path.insert(0, '${CLAUDE_PLUGIN_ROOT}')
   from hub_client import HubClient, load_config
   c = HubClient(load_config()); c.connect()
   print('каналы:', [x.get('name') for x in c.list_channels()]); c.close()"
   ```

5. Скажи, что для получения входящих прямо в сессию Claude нужно запускать
   с флагом `--channels plugin:teamhub@teamhub-marketplace`, иначе плагин
   останется просто набором инструментов. По умолчанию будят только
   обращения `@имя` и `@all`/`@here`.

6. Если проверка прошла — скажи, что нужно перезапустить Claude Code, чтобы
   плагин подхватил настройки. Если нет — покажи ошибку и помоги разобраться:
   чаще всего это неверный адрес, отсутствующая авторизация или недоступный по
   ключу сервер (в режиме `ssh` пароль спросить нельзя, нужен ключ).

Если пользователю удобнее сделать всё самому в терминале, подскажи команду:
`python3 ${CLAUDE_PLUGIN_ROOT}/teamhub_setup.py`
